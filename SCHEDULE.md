# Layer 6: put it on a schedule

In the Claude desktop app, open **Scheduled**, click **New task**, pick this folder, and paste one of the prompts below. Local tasks run on your machine, so the laptop needs to be on and the Claude app open at that time.

## Daily discovery (suggested: weekdays, early morning)

```
Run my job-search harness: the /find-jobs skill. Scheduled, unattended, discovery only.
Read CLAUDE.md first, then follow .claude/skills/find-jobs/SKILL.md exactly, step by step.
Final reply: the "At a glance" table, the top three GREEN or AMBER roles in one line each, and the "Needs you" section, under 250 words.
Never open an application form, apply, upload, save jobs, message anyone, create accounts, type passwords, or invent anything. Never run /calibrate.
```

## Follow-ups (suggested: twice a week, evening)

```
Run my job-search harness: the /follow-ups skill. Scheduled, unattended, drafts only.
Read CLAUDE.md first, then follow .claude/skills/follow-ups/SKILL.md exactly.
Final reply: anything needing me within 48 hours first, then replies and stage changes, then the number of drafts ready, under 200 words.
Never send, reply, forward, label, archive or delete email. Never message anyone. Never invent a name, address or fact.
```

/calibrate and /prep-application are never scheduled. They need you in the room.
